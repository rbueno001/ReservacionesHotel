# Sistema de Reservaciones de Hotel
## Descripción
Este proyecto es un sistema sencillo de reservaciones de hotel que desarrollé en Java para aplicar los conceptos de programación orientada a objetos vistos en clase.
El programa cuenta con 50 habitaciones de diferentes tipos y precios. Permite crear una reservación para un huésped y mostrar sus datos junto con el costo total de la estadía.

## Clases del proyecto
- **Hotel:** contiene las habitaciones y registra las reservaciones.
- **Habitacion:** guarda la información de cada habitación.
- **Huesped:** guarda los datos del huésped.
- **Reservacion:** contiene la información de la reservación.
- **Main:** ejecuta un ejemplo de reservación.

## Cómo ejecutar el programa
1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar `Main.java`.
